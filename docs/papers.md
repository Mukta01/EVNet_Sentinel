# EVNet Sentinel — Reference Papers Index

This document serves as the master index for all reference papers used to design and build the EVNet Sentinel project. 

The architecture, machine learning models, UI visualizations, and overall philosophy of EVNet Sentinel are heavily derived from these peer-reviewed research papers. We have documented our literature review paper-by-paper in the `docs/papers/` directory, extracting actionable insights, model hyperparameters, and architectural decisions.

## How to Use This Index

- Click any **Summary File** link to read the detailed, project-aligned documentation for that paper.
- Each summary extracts information specifically relevant to the EVNet Sentinel project: datasets used, models evaluated, attack vectors covered, and architectural insights.
- Papers are documented one at a time as instructed by the project owner.
