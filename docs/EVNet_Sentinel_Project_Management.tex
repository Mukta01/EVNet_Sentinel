\section{Project Overview}
\label{sec:overview}
% ============================================================================

\textbf{EVNet Sentinel} is an \tip{Intrusion Detection System (IDS)}{Monitors EVCS network traffic to detect cyberattacks such as DoS, MITM, and unauthorized commands.} for Electric Vehicle Charging Station (EVCS) networks. It combines static Machine Learning classifiers (\tip{RF}{Random Forest}, \tip{SVM}{Support Vector Machine}, \tip{LR}{Logistic Regression}, \tip{DT}{Decision Tree}) with an Online Learning engine (\tip{ARF + ADWIN}{Adaptive Random Forest with ADaptive WINdowing drift detector}) using the \textbf{CICEVSE2024} dataset.

The project reproduces and benchmarks the methods from \textbf{Makhmudov et al. (2025)} while delivering a state-of-the-art Next.js interactive dashboard inspired by modern design standards (\url{https://justus-john.com/en/}).

\begin{infobox}[System Architecture \& Ownership Tiers]
\begin{itemize}[nosep]
    \item \textbf{ML Engine \& Pipeline (Shardul Chogale):} Data cleaning, feature selection (RFE), static classifier training, ARF+ADWIN drift detection, model evaluation \& optimization.
    \item \textbf{Frontend \& API Integration (Neha Chavhan):} Next.js 16 UI components, application routing, REST API integration, WebSocket client manager.
    \item \textbf{Cloud Deployment \& DevOps (Mukta Varak):} Backend FastAPI server, Docker/cloud setup, CI/CD, CORS security, server environment configuration.
    \item \textbf{Data Visualization \& Testing DevOps (Shruti Chaurasiya):} Recharts metrics panel, confusion matrix heatmap, live alert stream UI, cross-browser \& E2E testing.
\end{itemize}
\end{infobox}
