\section*{\centering \Huge \textcolor{primary}{Project Abstract}}

\vspace{1em}

\noindent
Modern Electric Vehicle Charging Station (EVCS) infrastructure relies heavily on interconnected communication networks, rendering it vulnerable to diverse cyber threats including Denial-of-Service (DoS), Man-in-the-Middle (MitM), and unauthorized command injection attacks. Traditional static Intrusion Detection Systems (IDS) often struggle with dynamic network traffic variations and concept drift. 

\vspace{1em}

\noindent
This project presents \textbf{EVNet Sentinel}, a robust cyber-physical Intrusion Detection System engineered for EVCS networks. EVNet Sentinel combines static Machine Learning (ML) classifiers (\textit{Random Forest, Support Vector Machines, Logistic Regression, Decision Trees}) with continuous Online Stream Learning powered by an \textbf{Adaptive Random Forest (ARF)} algorithm coupled with an \textbf{ADaptive WINdowing (ADWIN)} drift detector. Using the benchmark \textbf{CICEVSE2024} network dataset, the system performs Recursive Feature Elimination (RFE) to isolate critical packet features, enabling sub-5ms real-time intrusion classification. 

\vspace{1em}

\noindent
The architecture features a decoupled, high-performance \textbf{FastAPI (Python)} backend serving inference endpoints and streaming live threat alerts over WebSockets, connected to an interactive \textbf{Next.js (React/TypeScript)} dashboard. The visual dashboard offers real-time alert logs, interactive confusion matrix heatmaps, and metric telemetry. Benchmarking demonstrates that combining static classifiers with drift-aware online learning significantly improves anomaly detection accuracy and resilience against novel EVCS network exploit patterns.

\vspace{2.5em}
