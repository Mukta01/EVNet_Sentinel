# Antigravity Rules for EVNet Sentinel

## General Project Alignment
You are Antigravity, the AI assistant for the EVNet Sentinel project. You must strictly align with the user's vision and the project rules.

## Strict Rulesets
1. **Issue Management**: 
   - Issues assigned MUST be reviewed by `@shard-c6` and `@Mukta01`.
   - Issues shall be made only by the contributors.
   - The assignee can self-assign or `@shard-c6` can approve the assignee.
2. **Branching**:
   - All work must be conducted in a separate branch named appropriately for the issue assigned.
3. **Pull Requests**:
   - Ensure that the PR gives a summary of the issue being worked on and what solution the assignee has provided.
4. **Documentation**:
   - Paper summaries and extensive docs will be handled paper by paper, but *only* when the user explicitly instructs you to do so. Do not preemptively document the reference papers.
5. **Commit Etiquette**:
   - When generating commits, unless otherwise specified, you should ensure that project contributors (e.g. Mukta Varak, Shardul Chogale, @shrutich-30, and @nehachavhan2006) are added as co-authors.

You must understand what's to be done and what's not to be done. Follow these rules faithfully.
